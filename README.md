# ShopHot

面向速卖通（AliExpress）等海外电商平台卖家的分析与效率工具网站。

## 项目目标

帮助卖家了解市场、分析商品与店铺，并通过实用工具提高日常运营效率。项目处于初始化阶段，具体功能和技术方案将在开发中逐步确定。

## 初步开发方向

- **商品与市场分析**：整理商品信息，观察价格、销量和市场趋势。
- **店铺与竞品分析**：对比店铺和商品，发现可用于选品与运营的线索。
- **卖家实用工具**：逐步提供利润估算、汇率换算和运营辅助工具。
- **多平台支持**：从速卖通相关场景开始，按需求扩展到其他海外电商平台。

以上为规划方向，尚未实现。数据来源、访问权限和可用指标需要在功能开发前确认；优先使用官方接口或用户授权的数据。

## 开发顺序

1. 确定首个核心场景、目标用户和数据来源。
2. 选择技术栈，搭建网站基础结构。
3. 完成首个可用功能，并添加相应验证。
4. 根据实际使用反馈扩展分析能力和便利工具。
