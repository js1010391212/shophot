使用指引

先核对商品和报价，再算实际成本，最后保留自己的研究过程。

先打开自己的报价

从已保存报价进入对应报告，再点击利润测算。这样商品、币种和来源会留在同一条研究路径里。

从我的报价开始 →没有报价，先手填情景

手填售价与成本是假设，不代表已采集到平台数据。

  1. 核对这件商品的报价

    打开报告，检查价格和币种、商品规格、收货国家、优惠及税运条件、来源与观测时间。历史报价不一定是当前价格；未知内容保留未知，不能当作 0 或“没有”。

    还没有报价时，可先查看浏览器采集安装与预览说明。只有预览信息核对正确后才确认保存，适用范围见下方。

  2. 算清采购、物流与费用

    在报告内进入利润测算，填写实际采购成本、包装和履约运费、广告及其它费用、平台与支付费率。售价与成本币种不同须填写实际换算汇率；引用报价只是售价假设，不会变成采购成本。

    物流可手填，也可使用物流报价，或导入自己的物流表格。公开参考不等于你的合同价，核对日期、路线、重量和附加费用，已计入的费用不要重复填写。

  3. 按需查看判断与测品预算

    利润页可启用成本视角选品判断和小批量测品预算。各项费用须明确填写；确认没有的费用填 0；成本未核对不能判为达标。预算区分准备资金、销售结算费用和假设全部售出的批次净利，未支出的预留资金不扣利润。

    这些结果只解释当前成本情景，不预测需求或销量，也不保证实际盈利。输入修改后须重新计算，错误时不能继续使用旧结果。

  4. 保存并继续研究

    计算成功后填写名称和备注，点击“保存最后成功计算”。在我的测算记录查看当时来源、假设与结果，也可继续测算、移出或恢复。

    历史记录不会被以后报价变化覆盖；继续测算需再次核对当前来源与物流。来源失效或条件改变时，按提示重选并重算。

目前哪些报价流程已验证？

eBay
0.1.1 仅一个刊登完成了安装点击 → 预览 → 确认 → 私有报告的实际验证。安装页可下载 0.1.2 测试包；可下载不等于实站验证，升级、第二件商品与多规格尚未验收，不能据此认为所有 eBay 商品可用。
AliExpress / 速卖通
当前尚未完成实时采集验收，官方应用准确 API 能力尚未确认。离线解析和联盟响应测试不代表实时采集成功，也不代表取得选中规格的价格。
手动观测与文件
可使用CSV 导入或已有商品的手动观测入口记录真实看到的数据，仍须提供来源、观测时间与报价条件。文件解析是否适配实际页面须单独核对，缺失销量或评价不能补成 0。

账号与问题反馈

我的浏览器报价与测算记录按账号私有保存；公共商品及非浏览器快照仍为共享研究资料。使用负责人提供的普通账号。需要创建或重置账号、遇到无法解释的报价或核算问题时，请联系负责人；不要把密码发到研究备注里。
